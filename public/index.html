ℹ️ AeroVector Architecture, Live Feeds & Radar Legend
🚀 What We Built & How It Works
🎯
Real-Time 60 FPS Canvas Vector Engine:
Renders 6,000+ active aircraft simultaneously using custom high-performance vector math across both 3D Orthographic Globe and 2D Equirectangular projections with solar day/night terminator.
⚡
Dead-Reckoning Physics Interpolation:
Interpolates aircraft latitude, longitude, altitude, and heading smoothly in real time between 10-second ADS-B broadcasts for butter-smooth visual motion without stutter.
🗄️
Embedded SQLite Cache Architecture:
High-speed local SQLite database (flights_cache.sqlite with WAL mode) caches verified flight routes, schedule times, and aircraft specifications—saving 98%+ of external API calls and eliminating rate limits.
🧠
Intelligent Flight Lifecycle & Staleness:
Evaluates flight departure, landing timestamps, and query age to automatically reuse active flight legs while re-querying only after a flight lands or expires.
📡 Aviation APIs & Data Feeds
OpenSky Network OAuth2 · Unlimited

Global Mode-S ADS-B transponder telemetry stream tracking 6,000+ airborne aircraft in real-time. Automatically filters out parked aircraft on airport gates.

AirLabs Aviation GDS API On-Demand Schedule

On-demand commercial airline schedule verification for clicked flights. Smart candidate resolver translates ATC transponder callsigns (e.g. IGO139V ➔ 6E139) to retrieve scheduled departure/arrival times, city names, and durations.

OpenFlights Navigation Database 13.7k Airports · 5.8k Airlines

Offline database of 13,768 international airports with IATA/ICAO codes, runway coordinates, elevation, and 5,852 international airlines.

📡 Top-Right Radar Stream Indicators & Degraded States Explained
LIVE (Green)

Active authenticated OpenSky Network feed. Broadcasts 6,000+ real-time aircraft every 120s with 60 FPS client dead-reckoning extrapolation.

SNAPSHOT (429 Rate Limit)

Upstream OpenSky daily credit limit reached (HTTP 429). AeroVector automatically falls back to 7,500+ baseline aircraft with continuous velocity physics so work and testing are never blocked. Automatically upgrades back to LIVE once quota resets.

RADAR HOLD

Radar feed stream temporarily paused or offline. Maintains last-known aircraft coordinates without discarding existing radar contacts.
